# GitHub Profile Viewer

A simple React app to search GitHub users and view their public profile and repository information.

## Features

* Search GitHub users
* View profile information
* View repositories
* View repository details
* Loading state
* Error handling
* Responsive UI

## Tech Stack

* React
* JavaScript
* Axios
* CSS
* GitHub REST API
* Jest
* React Testing Library
